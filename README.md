# Dolar até o Iphone vir

Painel em português para acompanhar o dólar comercial em reais. A página recebe atualizações da [biquote](https://biquote.io/docs/) e usa a [AwesomeAPI](https://docs.awesomeapi.com.br/api-de-moedas) como fonte de reserva. O conversor usa a cotação exibida junto com o horário de Brasília.

[Abrir o site](https://estudiocuringa.github.io/dolar-ate-o-iphone-vir/)
